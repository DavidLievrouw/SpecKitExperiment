# Modal Calendar Notification

## Prerequisites

- .NET SDK 10.0 preview or newer
- Windows 10 or newer (WPF runtime)

## Restore

```powershell
dotnet restore .\src\ModalCalendarNotification\ModalCalendarNotification.sln
```

## Build

```powershell
dotnet build .\src\ModalCalendarNotification\ModalCalendarNotification.sln
```

## Run Application

```powershell
dotnet run --project .\src\ModalCalendarNotification\ModalCalendarNotification\ModalCalendarNotification.csproj
```

## Run Tests

```powershell
dotnet test .\src\ModalCalendarNotification\ModalCalendarNotification.sln
```
